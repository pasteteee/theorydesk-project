# План реализации TheoryDeck

## Цель

Создать прототип «Доски теории» (Theory Board) для обсуждения фанатских теорий.
Стек: Next.js (App Router), TypeScript, Tailwind CSS, dnd-kit.

## Дизайн и UI

- **Стиль**: Премиальный темный интерфейс (Dark Mode).
- **Цветовая палитра**: Глубокие синие/серые тона фона, акценты (зеленый для "За", красный для "Против").
- **Анимации**: Плавные переходы при Drag-and-Drop, микро-анимации при голосовании.

## Архитектура

### Компоненты

1.  **Board**: Основной контейнер. Содержит состояние колонок и карточек.
2.  **Column**: Компонент колонки ("Evidence For", "Evidence Against"). Принимает список карточек.
3.  **FactCard**: Карточка факта. Отображает текст, счет (score) и кнопки голосования.
4.  **Library/AddFact**: Панель или модальное окно для добавления новых фактов.

### Модель данных (TypeScript)

```typescript
type FactType = "pro" | "con";

interface Fact {
  id: string;
  content: string;
  score: number;
  type: FactType; // Для определения колонки, если храним плоским списком, или просто принадлежность к колонке
}

interface ColumnData {
  id: FactType;
  title: string;
  facts: Fact[];
}
```

## Этапы разработки

### 1. Инициализация проекта

- Создать Next.js проект с TypeScript и Tailwind CSS.
- Очистить начальные стили.
- Настроить базовый лейаут и шрифты (Inter/Roboto).

### 2. Реализация UI компонентов (без логики)

- Сверстать карточку факта (`FactCard`).
- Сверстать колонки (`Column`).
- Сверстать панель добавления (`Library`).

### 3. Интеграция Drag-and-Drop (dnd-kit)

- Настроить контекст DND.
- Реализовать перемещение внутри колонки (сортировка).
- Реализовать перемещение между колонками.

### 4. Логика и Состояние

- Реализовать добавление новых фактов.
- Реализовать голосование (изменение Score).
- Моковые данные для демонстрации.

### 5. Полировка

- Анимации.
- Адаптивность (мобильная версия).
- Проверка UX.
