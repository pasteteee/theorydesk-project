# TheoryDeck

**TheoryDeck** — это интерактивная платформа для визуализации, анализа и обсуждения теорий. Здесь вы можете структурировать аргументы "За" и "Против", оценивать их вес и наглядно видеть, насколько правдоподобна та или иная теория.

---

## 📖 Руководство Пользователя

### 1. Основной Интерфейс

Экран разделен на несколько ключевых зон:

- **Evidence For (Аргументы ЗА)**: Левая колонка для фактов, подтверждающих теорию.
- **Evidence Against (Аргументы ПРОТИВ)**: Правая колонка для опровергающих фактов.
- **Панель Инструментов**: Включает библиотеку, фильтры, статистику и тренды.

### 2. Работа с Фактами

#### Создание Фактов

1. Найдите панель **Library (Библиотека)** в левой части экрана.
2. Введите текст своего факта или довода в поле ввода.
3. Нажмите `Enter` или кнопку `+`. Новый факт появится в очереди.

#### Организация (Drag & Drop)

- **Перетаскивание**: Зажмите иконку "ручки" (шесть точек) на карточке факта, чтобы переместить её.
- **Распределение**: Перетащите факт из библиотеки в колонку "За" или "Против".
- **Сортировка**: Вы можете менять порядок фактов внутри колонок, просто перетаскивая их вверх или вниз.
- **Мобильные устройства**: Перетаскивание оптимизировано для тач-экранов — страница не будет прокручиваться, пока вы двигаете карточку.

### 3. Оценка и Анализ

#### Голосование (Score)

У каждого факта есть рейтинг важности:

- Нажмите `^`, чтобы повысить значимость аргумента.
- Нажмите `v`, чтобы понизить его.
- Карточки с высоким рейтингом — это самые весомые доказательства.

#### Статистика (UserStats)

Визуальная школьная, показывающая баланс сил:

- **Зеленая полоса**: Процент аргументов "За".
- **Красная полоса**: Процент аргументов "Против".
  Это помогает мгновенно оценить, к чему склоняется теория.

#### Тренды (Trending Theory)

- Блок **Trending Theory** автоматически показывает "Лучший факт" на доске — тот, у которого самый высокий рейтинг среди всех аргументов (и "за", и "против").

### 4. Навигация и Поиск

#### Поиск

- Используйте строку **Search** вверху, чтобы быстро найти конкретный факт по ключевым словам.
- При клике на результат поиска, нужная карточка **подсветится** на доске, чтобы вы не потеряли её из виду.

#### Фильтры

Панель фильтров позволяет упорядочить доску:

- **By order**: Сортировка по времени добавления (новые внизу).
- **Best Fact**: Сортировка по убыванию рейтинга (самые сильные аргументы сверху).
- **Worst Fact**: Сортировка по возрастанию рейтинга.

### 5. Удаление

- Наведите на карточку, чтобы увидеть кнопку корзины (на мобильных устройствах может потребоваться тап).
- Нажмите на корзину, чтобы удалить факт с доски.
