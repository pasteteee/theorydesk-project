# TheoryDeck

**TheoryDeck** — это платформа для визуализации и обсуждения фанатских теорий (на примере One Piece).

## Как пользоваться

### 1. Доска Теории

Основной экран — это доска с двумя колонками:

- **Evidence For (Аргументы ЗА)**: Факты, подтверждающие теорию.
- **Evidence Against (Аргументы ПРОТИВ)**: Факты, опровергающие теорию.

### 2. Управление Фактами

- **Библиотека (Library)**:
  - Слева находится панель «Библиотека».
  - Создавайте новые факты здесь. Они служат вашим «черновиком».
  - Перетаскивайте факты из библиотеки в колонки «За» или «Против».
- **Drag-and-Drop**:
  - Перемещайте карточки между колонками, если ваше мнение изменилось.
  - Меняйте порядок внутри колонки, чтобы выделить самые важные аргументы.
- **Голосование (Score)**:
  - У каждой карточки есть рейтинг («Сила» аргумента).
  - Используйте `+` и `-`, чтобы изменить вес аргумента.
  - Карточки с высоким рейтингом автоматически поднимаются вверх.

### 3. Анализ

- Система автоматически подсчитывает «Вероятность теории» на основе разницы очков «За» и «Против».

---

## Запуск проекта

Установите зависимости:

```bash
npm install
```

Запустите сервер разработки:

```bash
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000) в браузере.
